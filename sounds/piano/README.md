# Piano samples

89 acoustic piano notes (A0 to Db8), one MP3 per key, named with flats (`Bb3.mp3`, `Db5.mp3`; a sharp is its flat
neighbour: C# = Db). Each is a short clip (128 kbps, 44.1 kHz, about 10 KB).

Source: https://github.com/fuhton/piano-mp3 (`piano-mp3/` folder, commit `1238aa3`), MIT licence, see `LICENSE`.
That repository says its samples were taken from https://github.com/gleitz/midi-js-soundfonts, which has its own
licence terms for the underlying soundfont: check them before publishing this app widely.
